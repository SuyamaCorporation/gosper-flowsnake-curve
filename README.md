# 30 - ゴスパー曲線フラクタル描画

**ビルド日**: 2026-11-03
**カテゴリ**: visual
**slug**: gosper-flowsnake-curve

## 概要
L-systemルール（A→A-B--B+A++AA+B-、B→+A-BB--B-A++A+B）を使ってゴスパー曲線（フローズネイク）を生成するフラクタル描画アプリ。レベル1〜5まで選択可能。

## 機能
- Canvas上にゴスパー曲線をリアルタイム描画
- レベルスライダー（1〜5）でフラクタルの詳細度を調整
- アニメーション描画（白い点が曲線をトレース）
- 速度スライダーでアニメーション速度を調節
- HSLグラデーションによるカラー曲線
- PNG形式でダウンロード
- レベル・セグメント数の情報表示
